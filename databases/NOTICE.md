# Databases — Sources and Licenses

Three of the SQLite databases included here are public sample databases, redistributed unchanged for reproducibility. The fourth (`ledger.sqlite`) is a first-party synthetic database created for this benchmark.

| File | Source | License |
|---|---|---|
| `sakila.sqlite` | [MySQL Sakila](https://dev.mysql.com/doc/sakila/en/) sample, SQLite port | BSD-style, free to redistribute |
| `chinook.sqlite` | [Chinook Database](https://github.com/lerocha/chinook-database) by Luis Rocha | MIT |
| `northwind.sqlite` | Microsoft Northwind sample, SQLite port | MIT-style, public sample |
| `ledger.sqlite` | First-party synthetic (held-out suite), generated by [`scripts/generate_ledger.py`](../scripts/generate_ledger.py), seed-deterministic. All company names, people, amounts and entries are fabricated; first published in this repository (July 2026) | MIT (same as the repository) |

These databases are included for **benchmarking purposes only**. They are not part of GBAG itself — GBAG is the dataset (`data/questions.jsonl`), the metric (`METRIC.md`), and the judging protocol (`judge/`).

If you reuse the databases in your own work, please credit the original authors above.
